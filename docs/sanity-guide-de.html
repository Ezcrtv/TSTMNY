So verwaltest du die Testimonies auf deiner Website

Alle Geschichten auf der Website liegen in Sanity Studio. Dort erfasst und bearbeitest du Testimonies und gibst Einsendungen frei. Die Website aktualisiert sich danach von selbst. Code musst du nie anfassen.

Das Studio selbst ist auf Englisch. Knöpfe und Felder sind deshalb hier so geschrieben, wie du sie im Studio siehst, zum Beispiel Publish.

Anmelden

  1. Nimm die Einladung von Sanity per E-Mail an und melde dich mit Google, GitHub oder E-Mail an. Verwende jedes Mal dasselbe Login.

  2. Öffne deinedomain.ch/studio und speichere die Seite als Lesezeichen. Hier liegen alle Inhalte.

  3. Links siehst du die Inhaltstypen: Testimony, Topic, Sport und Site Settings. Klicke auf einen Typ, um die Liste zu sehen, und dann auf einen Eintrag, um ihn zu öffnen.

Die eine Regel: Approved + Publish

Ein Testimony erscheint nur dann auf der Website, wenn der Status auf Approved steht und du auf Publish geklickt hast.

Änderungen sind innert etwa einer Minute live. Falls noch nichts zu sehen ist, warte kurz und lade die Seite neu.

Pending heisst: versteckt. Das ist für Entwürfe und alles, was du noch prüfst. Approved heisst: bereit für die Öffentlichkeit.

Mit Publish (unten rechts) überträgst du deine Änderungen auf die Live-Version. Bis dahin bleiben sie ein Entwurf, den nur du im Studio siehst.

Neues Testimony erfassen

  1. Klicke auf Testimony und dann oben auf + bzw. Create.

  2. Gib den Title ein und klicke beim Feld Slug auf Generate. Der Slug wird zur Webadresse der Seite, z. B. /testimony/the-day-i-came-back.

  3. Fülle die übrigen Felder aus (siehe Tabelle unten). Pflicht sind nur Title, Slug, Name der Person und Status. Am besten wirkt eine Geschichte aber mit Bild, Excerpt und Pull quote.

  4. Setze Status auf Approved und klicke auf Publish.

Videos hinzufügen

Videodateien werden nicht direkt ins Studio hochgeladen. Stattdessen:

  1. Lade den Clip auf YouTube (auch «nicht gelistet» funktioniert) oder Vimeo hoch.

  2. Kopiere den Link und füge ihn im Testimony unter Video URL ein.

  3. Klicke auf Publish.

Eingesandte Geschichten prüfen

Wenn jemand auf der Kontaktseite «Share my testimony» ausfüllt, passieren zwei Dinge: Du bekommst eine E-Mail, und im Studio erscheint ein neues Testimony mit Status Pending. Was auf Pending steht, wird nie auf der Website angezeigt.

  1. Öffne Testimony und such den neuen Eintrag.

  2. Lies ihn und überarbeite den Text. Ergänze Title, Bild, Sport, Topics, Excerpt und Pull quote.

  3. Wenn alles passt, setze Status auf Approved und klicke auf Publish. Passt er nicht, lass ihn auf Pending oder lösche ihn.

Sportarten und Themen

Daraus entstehen die Filter auf der Testimonies-Seite. Eine neue Sportart oder ein neues Thema ist ein Eintrag im Studio, keine Änderung an der Website.

  1. Klicke auf Sport (oder Topic) → Create.

  2. Gib den Namen ein, z. B. «Basketball» oder «Grief», klicke beim Slug auf Generate und dann auf Publish.

  3. Öffne ein Testimony und wähle den Eintrag im Feld Sport bzw. Topics aus.

Ein Thema erscheint als Filter, sobald mindestens eine freigegebene Geschichte es verwendet. Der Sport-Filter erscheint, sobald die Geschichten zwei oder mehr Sportarten abdecken.

Bearbeiten, verstecken, löschen

  • Tippfehler korrigieren: Testimony öffnen, ändern, auf Publish klicken.
  • Geschichte vorübergehend verstecken: Status zurück auf Pending setzen und Publish klicken. Sie verschwindet von der Website, bleibt aber gespeichert.
  • Endgültig entfernen: Im Menü ⋯ neben Publish auf Delete klicken. Das lässt sich nicht rückgängig machen, Verstecken ist deshalb meist sicherer.
  • Fehler rückgängig machen: Das Uhr-Symbol (oben rechts im Dokument) zeigt den Verlauf. Dort kannst du eine frühere Version wiederherstellen.

Was du ignorieren kannst

  • Felder mit (legacy), etwa Sport (legacy text), Themes (legacy), Category (legacy) und Short Description. Sie stammen aus einer älteren Version. Wenn du eine ältere Geschichte bearbeitest, wähle Sport und Topics aus und leere dann das Legacy-Feld.
  • Site Settings. Die Texte der Startseite und die Social-Media-Links sind im Moment direkt im Website-Code hinterlegt. Für Änderungen melde dich beim Entwickler.
  • Den Tab Vision im Studio. Das ist ein Werkzeug für Entwickler.
